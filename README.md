# COMP6013 Week 7 — Quantum Crypto Studio

Interactive student-facing lecture website for **Lightweight Cryptography and Post-Quantum Cryptography**.

## Included

- 10 lecture modules with detailed explanations
- Click-to-flip deep-dive concept cards
- Interactive device examples
- Security / performance / cost trade-off activity
- Animated side-channel leakage visualiser
- 2-question quick check after every module (20 mini questions)
- 7-question final quiz
- Responsive sidebar navigation

## Vercel

This repository is Vercel-ready. The build concatenates the checked-in HTML payload chunks into `dist/index.html`.

- Build command: `npm run build`
- Output directory: `dist`
